# Push karne ke steps (thakur2309/thakur2309)

Tumhari profile repo pehle se hai, to purani README ko is se replace karna hai.

```bash
git clone https://github.com/thakur2309/thakur2309.git
cd thakur2309
# is folder ki saari files (README.md, svg/, .github/) clone wale folder mein copy karo
git add .
git commit -m "feat: new cyber security profile"
git push origin main
```

Uske baad ek baar:
1. Repo → Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save
2. Actions tab → "Generate Contribution Snake" → **Run workflow**
3. Actions tab → "3D contribution city" → **Run workflow**

Dono workflows 1-2 minute mein snake aur 3D city bana dengi, tab tak un do images ki jagah khali dikhegi.
