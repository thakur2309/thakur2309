# GitHub Profile README — thakur2309

## Install
1. Open https://github.com/new
2. Create a **public** repository named exactly `thakur2309` (same as your username).
3. Upload the contents of this ZIP to the repository root. Do not upload the enclosing folder itself.
4. Ensure `README.md`, `assets/`, and `.github/workflows/snake.yml` appear at the root.
5. Open **Settings → Actions → General** and allow GitHub Actions.
6. Open **Actions → Generate contribution snake → Run workflow** once.
7. After the workflow succeeds, the contribution snake image will appear. It may take a few minutes.

## Notes
- This package does not modify any of your existing repositories.
- GitHub profile README only displays automatically when the repository name exactly matches your username and is public.
- GitHub stats cards and contribution snake are externally generated images. Third-party services can have occasional downtime.
- The Firewall Breaker website link and Rakshak Firewall product link are included. The live Rakshak page was readable during preparation; the Firewall Breaker domain timed out during inspection, so review its destination and public pages yourself before publishing.
- Check all social/profile links and remove anything you do not want public.
