# Alok Thakur — Premium Cybersecurity GitHub Profile

This package intentionally follows the structure of the reference profile you shared:
- 5 large custom SVG infographic panels in `svg/`
- Featured projects table in README
- Developer ID / dashboard panel
- 3D contribution city generated by GitHub Actions
- Contribution snake animation generated by GitHub Actions

## Upload safely

1. Open your existing profile repository: https://github.com/thakur2309/thakur2309
2. Download/keep a backup of its current README before replacing anything.
3. Extract this ZIP.
4. Upload the `README.md`, `svg/` folder and `.github/` folder to the repository root. You can also upload the whole contents through GitHub's Upload files page.
5. Do not delete or replace unrelated folders/files already in the repository.
6. In Settings → Actions → General, allow GitHub Actions to run and allow workflows to create and approve pull requests / write repository contents if the setting is present. The workflows need repository contents write permission.
7. Open Actions and manually run both `3D contribution city` and `Generate contribution snake`.
8. Wait for both workflows to complete. The 3D city file is generated in `profile-3d-contrib/`; the snake is published to the `output` branch.

## What the visuals are

- `svg/hero.svg`: custom cyber-operations hero banner
- `svg/about-life.svg`: custom terminal-style profile / interests panel
- `svg/stack.svg`: custom skills and technology infographic
- `svg/id-dashboard.svg`: developer identity card / GitHub activity panel
- `svg/connect.svg`: custom social and product links panel
- `profile-3d-contrib/`: generated by `yoshi389111/github-profile-3d-contrib`
